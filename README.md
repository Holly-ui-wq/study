# Study Buddy · 学习打卡助手

Vue 3 + Vite + Vue Router 纯前端课程项目。包含 3 个页面、17 个 Vue 单文件组件、响应式任务管理、组件 props/emits、v-model、v-if/v-for、computed、async/await 模拟异步保存、CSS 动画和 localStorage 持久化。

## 页面
- 今日计划：添加任务、完成/撤销、删除、进度统计
- 学习统计：学习时长柱状图、任务分类
- 我的目标：每日时长目标、连续打卡、成就徽章

## 在线使用
打开 https://stackblitz.com/fork/vue ，把项目文件上传或复制进去即可在浏览器运行。在线编辑器无需本地安装。公网部署可在 StackBlitz 中分享，或导入 Netlify。

## 本地运行（可选）
需要 Node.js 18+：`npm install`，然后 `npm run dev`。
